# StyleScript :: Skizze

- bastardsprache aus css und js/ts
- wird zu css compiled (und je nachdem evtl. bisschen js)
- syntax-ausgangspunkt ist css (in seiner grundform, nicht wie aktuell)
- im wesentlichen gibts:
  - configs/schemas
  - direkt
  - rulesets
  - scriptblöcke
- wo es möglich ist, wird sich css-semantik orientiert

## css

- modernes is gefühlt schon halbe programmiersprache, aber halt auch wirklich nur halb
- moderne css-features sind nice, aber modernes css zu schreiben ist messy af:
  - überall `{}` und nesting
  - absurde selector-konstrukte
  - überall `--` bzw. `--()` und 5 level deep ineinanderverkettet
  - inkonsistente property-namen
  - und so weiter
